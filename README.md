# Kichuma Structures

A modern static website for a leading adventure and construction company in Kenya, focused on zipline installations, high ropes, sky cycling, giant swings, and structural cabling solutions.

This project presents Kichuma Structures as a professional brand through a premium landing page, service details, project gallery, and a guided booking flow.

## Live Preview

GitHub Pages preview URL:

https://branhamsimiyu8289.github.io/kichuma-structures/

## Overview

Kichuma Structures is a business website designed to help clients:

- explore the company’s service offerings
- view completed adventure installations and projects
- understand the company’s work quality and experience
- request bookings through an interactive front-end process
- contact the company through a clear business contact section

The site is built using a simple front-end stack with no heavy framework, making it fast, lightweight, and easy to deploy.

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla ES6+)
- Google Fonts
- Font Awesome Icons
- YouTube video embeds
- Python support script (`kichuma.py`)

## Features

- responsive single-page navigation
- bold hero section with brand positioning
- service cards with animated hover effects
- detailed service information pages
- project gallery with modal popups
- contact information and social links
- multi-step booking workflow with OTP-style verification
- scrollable service showcase
- visually rich adventure-themed design

## How to Run locally

### Option 1: Open directly

Open the project folder and launch `index.html` in your browser.

### Option 2: Use a local web server

```bash
cd kichuma-structures
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
